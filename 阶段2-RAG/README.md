# 阶段 2 · RAG（检索增强生成）

**核心问题**：资料太多塞不进去，怎么办？

**一句话定位**：RAG 不是「让 AI 更聪明的技术」，而是**一条把资料在提问那一刻递过去的流水线**。
本阶段所有判断，都围绕「这条流水线的哪一步会断」展开。

## 本阶段最该记住的几句

> **RAG 的存在理由只有一个：资料塞不进上下文窗口。** 塞得进就用 Prompt。
>
> **离线三步建索引，在线两步查索引。** 出问题先判断卡在哪一边——
> **「慢」往在线查，「错 / 找不到」往离线查。**
>
> **确定性答案交代码，模糊性答案交模型。** RAG 只管把资料递过去。
>
> **知识库管群体公共知识，用户记忆管个体差异。** 问「记忆」只答 RAG 是答偏的。
>
> **索引是可重建的派生物，所以新旧两套能同时存在**（换灯泡不停电）。
>
> **RAG 给的是知识，微调改的是风格和习惯。**（收口句，面试用）

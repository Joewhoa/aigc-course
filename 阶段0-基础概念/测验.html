二、简答题（每题 1 分，共 4 分｜答到要点就给分）

Q7
用自己的话说清楚：Token 是什么？它跟「钱」和跟「忘性」分别是什么关系？
（要点 3 个，缺一个扣 0.3 分）
要点（3 个，缺一个扣 0.3 分）：
1. Token 是模型处理文字的最小单位，不等于字也不等于词
2. 它跟钱的关系：按 token 双向收费，输入和输出分开计价，输出更贵
3. 它跟忘性的关系：上下文窗口按 token 计上限，超了就丢掉最早的内容，表现为「忘」
Q8
「模型不执行，它只输出文字。」
请用一个「用自然语言远程控制电脑」类的项目（比如手机远程控制台）举例，说明这句话里：哪部分是模型干的？哪部分不是模型干的？
要点：
· 模型干的：理解自然语言 → 生成「要执行什么动作」的指令
· 不是模型干的：真正的文件读写、命令执行、结果回传——那是外层程序在干
· 加分：模型是「提议者」，程序是「执行者」；模型从头到尾没碰过被控制的机器
Q9

现在有人提出这个需求：

「我要做一个能回答内部制度文档问题的 AI，文档一共 800 页，每个月更新一次。」

四个手段：Prompt / RAG / Agent+工具 / 微调，选哪个？为什么选它？再说明为什么不是另外那三个中最容易选错的那个。

要点：
· 选 RAG
· 理由：知识是私有的（模型没学过）+ 文档频繁更新（微调跟不上）+ 需要可溯源
· 最容易选错的：微调。因为它看起来「更彻底」。但微调改变的是风格不是知识，而且文档一更新就得重训，成本高还不准
· 顺带排除：Prompt 塞不下 800 页；Agent 在这里是过度设计

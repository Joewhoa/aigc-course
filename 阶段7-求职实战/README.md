# 阶段 7 · 求职实战

**核心问题**：怎么把学过的东西讲清楚、讲得让人信？

## 本阶段学什么

| 节 | 内容 |
|---|---|
| 7.1 | 先纠正一个误区：考核的不是记忆，是能不能做事 |
| 7.2 | **项目怎么讲**（STAR 的 AI 版，重点在 A 段）＋ ⭐ **「审核者不是提议者」这个定位** |
| 7.3 | **怎么解释背景转变**（三条原则 + 完整表述模板） |
| 7.4 | 章节小测（概念类 / 工程类 / 场景类）＋ ⚠️ **「六步 / 四道防线」的口径桥接** |
| 7.5 | 简历怎么写（写成果和判断，不写技术栈清单） |
| 7.6 | 遇到不会的问题怎么应对 |
| 7.7 | 章节小测（元问题：怎么介绍自己） |
| 7.8 | ⭐⭐ **被要求写代码时怎么答** |
| 7.9 | ⭐⭐ **AI 岗位分层：怎么认准方向，别被 K8s 带跑** |
| 7.10 | **最后一件事：把七个阶段串成一句话** |

> 共 **10 节**。
>
> **7.8 / 7.9 是本阶段最该读的两节**——
> 它们各解决一个你**一定会遇到、但技术课上原本没答案**的问题：
> 「被要求写代码怎么办」「为什么最近满屏都是 K8s」。
>
> **7.10** 是全课收口 —— 别人问「你懂 AI 吗」时，
> 你要能用一句话把整个方法论串起来。

## 文件

- `讲义.html` —— 正文（10 节）
- `测验.html` —— **表述训练**，5 题，**无选择项**，按「讲得对不对」评分

## 过关标准

- 有真实项目细节（不是空话）
- 有判断过程（为什么这么选）
- **主动讲出「我是审核者」这个定位**（不等别人问）
- 被要求写代码时**没被打倒**，且**没说出「会写代码的人没价值」**
- 能用「**用 vs 造/训**」这条判据当场把一个岗位分到正确的层
- 遇到不会的，守住「不硬编」这条线

## 本阶段最该记住的一句

> **你在项目里的角色是「审核者」——这是定位，不是短板。**
> 定验收条件 ＋ 独立核对 ＋ 让 AI 列出没验的。

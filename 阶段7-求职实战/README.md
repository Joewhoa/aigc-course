# 阶段 7 · 求职实战

**核心问题**：怎么把这些讲成面试官想听的答案？

## 本阶段学什么

| 节 | 内容 |
|---|---|
| 7.1 | 面试不是在考试——面试官真正判断什么 |
| 7.2 | **项目怎么讲**（STAR 的 AI 版，重点在 A 段）＋ ⭐ **「你是审核者不是提议者」的角色定位** |
| 7.3 | **转行怎么解释**（三条原则 + 话术模板） |
| 7.4 | 高频面试题清单（概念类 / 工程类 / 场景类）＋ ⚠️ **「六步 / 四道防线」的口径桥接** |
| 7.5 | 简历怎么写（写成果和判断，不写技术栈清单） |
| 7.6 | 面试现场怎么应对不会的问题 |
| 7.7 | 面试会怎么问（元问题） |
| 7.8 | ⭐⭐ **被要求写代码 / 面试代码题时怎么答**（本阶段新增） |
| 7.9 | ⭐⭐ **AI 岗位分层：怎么认准方向，别被 K8s 带跑**（本阶段新增） |
| 7.10 | **最后一件事：把七个阶段串成一句话** |

> 它们各解决一个你**一定会遇到、但课里原本没答案**的问题：
> 「被要求写代码怎么办」「为什么最近满屏都是 K8s」。
>
> **7.10** 是全课收口 —— 面试官问「你懂 AI 吗」时，
> 你要能用一句话把整个方法论串起来。

## 过关标准

- 有真实项目细节（不是空话）
- 有判断过程（为什么这么选）
- **主动讲出「我是审核者」这个角色定位**（不等我问）
- 被要求写代码时**没被打倒**，且**没说出「会写代码的人没价值」**
- 能用「**用 vs 造/训**」这条判据当场把一个岗位分到正确的层
- 遇到不会的，守住「不硬编」这条线

## 本阶段最该记住的一句

> **你在项目里的角色是「审核者」——这是定位，不是短板。**
> 定验收条件 ＋ 独立核对 ＋ 让 AI 列出没验的。

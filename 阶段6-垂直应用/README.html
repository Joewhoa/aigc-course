本阶段最该记住的四句

垂直应用 = 把通用能力装进具体场景——价值在对场景的理解，不在模型本身。

行业正从「能做事」转向「可靠地做事」——竞争力在工程，不在调模型（这正是阶段 3–5 的内容）。

手段有顺序：先提示词 → 再工作流 → 最后自主 Agent；Agent 不是更高级，是更不可控。

框架是工具，不是信仰。 直接的 API 调用优于复杂框架——因为每层抽象都是一个调试盲区。

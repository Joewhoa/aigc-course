## 一、选择题（每题 1 分，共 6 分）

**Q1.** 「垂直应用」和「通用能力」最本质的区别是？
> 考点：6.1

- A. 用的模型不一样
- B. 垂直应用是把通用能力装进具体场景，解决一个具体问题
- C. 垂直应用不需要模型
- D. 垂直应用运行更快

---

**Q2.** MCP（Model Context Protocol）主要解决什么问题？
> 考点：6.3

- A. 让模型变聪明
- B. 统一工具 / 数据源的接入接口，解决工具接入碎片化、让工具能被复用
- C. 加快模型推理速度
- D. 降低模型价格

---

**Q3.** **A2A 和 MCP 的核心区别是？**
> 考点：6.3

- A. A2A 是 MCP 的升级版，功能更多
- B. MCP 连「工具 / 数据」，A2A 连「另一个 Agent」
- C. A2A 只能在本地用，MCP 只能联网用
- D. 两者完全一样

---

**Q4.** 你要判断某个系统是否该用 **Computer Use（会操作电脑的 Agent）**，第一步应该问什么？
> 考点：6.7

- A. 它的界面好不好看
- B. 这个系统有没有 API / 数据接口？有就优先用 API
- C. 电脑配置够不够好
- D. 模型能不能识别截图

---

**Q5.** 一个新场景落地，**选技术手段**时，下面哪个顺序是对的？
> 考点：6.5

- A. 自主 Agent → 工作流 → 提示词（从高级往低级）
- B. 先优化提示词 → 再考虑工作流 → 最后才引入自主 Agent
- C. 哪个技术最新用哪个
- D. 看团队里谁最熟用哪个

---

**Q6.** 关于 LangChain 这类框架，下面哪个判断是对的？
> 考点：6.9

- A. 用了框架的项目一定更专业
- B. 框架不是免费的——每多一层抽象就多一个调试盲区，流程简单时直接调 API 更好
- C. 学会框架用法最重要，别的都不重要
- D. 框架能提升模型本身的推理能力

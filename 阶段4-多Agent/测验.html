二、简答题（每题 1 分，共 8 分｜答到要点就给分）

Q7

不共享上下文的协作，靠两个平面支撑。
请分别说出数据平面和控制平面各管什么（各一句话），
并说出控制平面管的是哪四件事。

考点：4.3

考点：4.3。要点：
· 数据平面管「东西放哪」：产物交换、文件系统布局（四类区域）
· 控制平面管「谁在干什么、要不要停、给多少钱」：消息传递 / 状态查询 / 执行终止 / 资源调度
· 书里原句：「产物交换（数据平面）与消息传递、状态查询、执行终止、资源调度（控制平面）共同支撑起不共享上下文的多 Agent 系统」
· ⚠️ 四件事缺一即漏项：消息传递、状态查询、执行终止、资源与调度
Q8

多 Agent 之间传消息，为什么要求消息带一个统一的「信封」？
信封里至少要有什么？这一条为什么被说是「多 Agent 系统调试的关键」？

考点：4.3.2

考点：4.3.2。要点：
· 信封内容 = 发送者 ID + 目标（指定 Agent 或广播）+ 消息类型（task_assigned / status_update / result / terminate）+ JSON 负载
· 作用：保证接收方能够可靠地路由和解析消息
· 关键句（必须答到这层）：「使协作链路可追溯——这是多 Agent 系统调试的关键」
· 只答「格式统一」不够，要答出「可追溯 / 可调试」
Q9

请说出「过早终止」的三种形态，以及它和「循环失控」是什么关系。
再写出书里总结的那句根因。

考点：4.4

考点：4.4。要点：
· 三种形态：① 偷懒式假完成 ② 过早放弃 ③ 假成功
· 与循环失控的关系：正好相反的两个方向（一个停不下来，一个停得太早）；而且过早终止更常见、更隐蔽，因为它长得像成功
· 根因原句：「在验证之前，「完成」只是模型的一句宣称，不是证明」
· 加分：「循环的瓶颈在验证器，而不在模型」
Q10

关于反思（Reflection）机制：为什么「让模型自己审自己」经常是无效的？
请说出研究报告的结论，以及有效反思的两条硬条件。

考点：4.5

考点：4.5。要点：
· 无效的原因：没有引入新信息——同一模型、同一份材料再想一遍
· 研究结论：ICLR 2024《Large Language Models Cannot Self-Correct Reasoning Yet》——让 GPT-4 在没有外部反馈下审查并修正自己，准确率反而下降，改错的次数比改对的多
· 两条硬条件（缺一即漏项）：
  ① 审核者读取独立证据，而不是只复述提议者的解释
  ② 审核者不能修改测试、证据采集器或发布门槛——否则「独立验证」会退化成自我批准
Q11

记忆的「记忆层次」这一套分几层？分别是什么、各存什么？
另外请说出记忆还有哪两套正交的分类体系，以及「工作记忆」指的是什么。

考点：4.5

考点：4.5。要点：
· 记忆层次（回答「存在哪里」）三层 = 轨迹（当前会话的完整事件序列）/ 用户长期记忆（跨会话的事实偏好）/ 业务状态（任务进行到哪一步）
· 另两套正交体系：存储格式（回答「怎么存」）+ 认知类型（回答「存什么」：情景 / 语义 / 程序记忆）
· 「工作记忆」是认知科学的说法，对应 Agent 的上下文窗口——是处理当前任务的临时空间，不是「存到文件里的东西」，别和业务状态混
Q12

多 Agent 的七种失败模式里，哪一种是「人的问题、技术解决不了」？
它包含哪两种具体表现？为什么说这门课存在的意义就是治它？

考点：4.4

考点：4.4。要点：
· 第 7 条：理解债与认知投降
· 两种表现：理解债（Agent 交付太快，人对系统的理解落后，出事看不懂）+ 认知投降（习惯了让它代劳，放弃独立审查）
· 为什么这门课治它：不写代码、项目全由 AI 交付，这条路的风险正是这条；关键是区分外包「写代码」（可以）vs 外包「理解」（危险）
· 加分：Karpathy 那句「你可以外包你的思考，但不能外包你的理解」
Q13

面试官问：「什么时候不该用多 Agent？」请给出回答，并说出判据和一个反例。

考点：4.1

要求：成段说，不要分点符号。

考点：4.1。成段作答，要点：
· 判据：协作有没有引入单个 Agent 生成时拿不到的新信息
· 没有就别拆——多出来的成本是几倍到十几倍（书里原话「收益必须足够大，能够覆盖数倍乃至一个数量级的额外开销」）
· 反例（任一）：让模型重新读自己的输出 / 两个同模型 Agent 辩论同一段材料（等计算量下与单 Agent 持平）
· 加分：对照正例——审核者用「测试执行结果 / 渲染截图 / 外部工具验证」，这些引入了新信息，所以有效
· 收口句加分
Q14

面试官问：「一个复杂的 Agent 任务，怎么保证它不迷路、不忘事、不跑偏？」
请给出回答。结尾必须有一个收口句。

考点：4.5

要求：成段说，不要分点符号。

考点：4.5。成段作答，三个补丁各对应一个问题（缺一扣分）：
· 不迷路 → 规划：先列计划再执行，或边做边规划（ReAct）。加分：光给步骤上限不够，要让它有预算意识（前期广探、后期聚焦）
· 不忘事 → 记忆：轨迹 / 用户长期记忆 / 业务状态；本质是「存在外面，用时读回来」
· 不跑偏 → 反思：但必须是有效反思——读独立证据、不能自己改验收标准
· ⚠️ 题面要求结尾有收口句——能收成一句（如「三个补丁解决三类不同的失效，而其中最容易被忽略的是——验证必须独立于被验证者」）即达标

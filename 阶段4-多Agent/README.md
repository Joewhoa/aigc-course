# 阶段 4 · 多 Agent 协作

**核心问题**：一件事太复杂，怎么拆给多个角色分工？——以及**什么时候根本不该拆**。

| 4.2 | **三种协作拓扑**（流水线 / 主管-下属 / 辩论互审）＋ **两个维度框架** |
| 4.3 | ★ **不共享上下文的协作**：**数据平面 / 控制平面** ＋ 虚拟文件系统**四类区域** ＋ **三种通信机制** ＋ **信封协议** |

阶段 4 · 多 Agent 协作

核心问题：一件事太复杂，怎么拆给多个角色分工？——以及什么时候根本不该拆。

本阶段最该记住的两句

多 Agent 是拆解，不是升级——判据只有一条：协作有没有引入单个 Agent 拿不到的新信息？

模型说「完成」，那只是一句宣称，不是证明（因为 Agent 的故障是拜占庭式的）。

# 阶段 3 · Agent + 工具调用

**核心问题**：怎么让它不光会说，还能动手做事？

## 本阶段学什么

| 节 | 内容 |
|---|---|
| 3.1 | Agent 和「会聊天的模型」差在哪（= 模型 + 工具 + 循环 + **环境**） |
| 3.2 | **工具调用六步机制**（模型只出请求，程序才执行）；上下文 = **静态前缀 + 轨迹** |
| 3.3 | ReAct：边想边做（想 / 做 / 看） |
| 3.4 | **四道防线 + 三层护栏**（权限最小化 / 高风险确认 / 参数校验 / 轮次成本上限；护栏分上下文层·执行层·数据层） |
| 3.5 | 怎么证明它干对了：测试驱动开发（先定验收条件） |
| 3.6 | **编排模式：工作流 vs 自主 Agent**（★ 本阶段最该记的一节） |
| 3.7 | 工具的五种类型（以及工具该怎么设计） |
| 3.8 | 章节小测：能答上来才算真会了 |

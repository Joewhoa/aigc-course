## 一、选择题（每题 1 分，共 6 分）

**Q1.** Agent 和普通模型调用最本质的区别是什么？
`考点：3.1`

- A. Agent 用的模型更大
- B. Agent 支持多模态输入
- C. Agent 多了一个循环：能看到执行结果再决定下一步
- D. Agent 运行速度更快

---

**Q2.** 工具调用过程中，真正执行那个工具的是谁？
`考点：3.2`

- A. 模型自己
- B. 工具自己会响应
- C. 用户手动执行
- D. 外层程序（harness）

---

**Q3.** 模型是怎么「请求」调用工具的？
`考点：3.2`

- A. 输出一段结构化文本（通常是 JSON）
- B. 直接调用工具的函数
- C. 发一个网络请求给工具
- D. 弹窗询问用户

---

**Q4.** ReAct 循环里的三个动作是？
`考点：3.3`

- A. 输入 / 处理 / 输出
- B. 读 / 写 / 改
- C. 想 / 做 / 看（Thought / Action / Observation）
- D. 提问 / 回答 / 确认

---

**Q5.** Agent 反复调用同一个工具、停不下来。最直接有效的防线是？
`考点：3.4`

- A. 换一个更强的模型
- B. 在提示词里写「不要重复」
- C. 把温度调到 0
- D. 设置最大轮次上限

---

**Q6.** 要让 Agent 能删除服务器上的旧文件。最稳妥的做法是？
`考点：3.4`

- A. 直接授权，效率最高
- B. 不把这个工具给它；或者要求执行前先人工确认
- C. 在提示词里提醒它「小心操作」
- D. 换一个更贵的模型
